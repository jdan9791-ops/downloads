| 프로그램 | 설명 | 받기 |
|---|---|---|
| Video Grabber | 브라우저가 내장된 동영상 다운로드 프로그램 | [최신 버전](https://github.com/jdan9791-ops/downloads/releases?q=video-grabber) |

- 설치 없이 exe를 더블클릭하면 실행됩니다.
